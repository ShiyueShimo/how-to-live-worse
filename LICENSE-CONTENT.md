## Changes made here

This project reorganizes the source into a searchable reading site, preserves original text and evidence context, and adds original satirical inversions, prompts, essays, glossary analogies and interface copy. The reversals are new editorial material. They do not replace or purport to revise the evidence in the source guide. Sensitive health, emergency, legal, financial and personal-safety content remains factual and source-linked.

The separate website at [howtolivebetter.net](https://howtolivebetter.net/) informed the observed list of features and topic coverage only. This project does not include that website's prose, art, name or code.
